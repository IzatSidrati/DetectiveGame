# Panduan Ilustrasi Komik MindCase (Gaya Komik Kartun Ekspresif / Ace Attorney)

Letakkan file gambar (`.png`, `.jpg`, `.jpeg`, atau `.webp`, rasio **16:9**) di folder `assets/images/` ini dengan nama file persis di bawah. Aplikasi akan **otomatis memuat gambarnya tanpa perlu ubah kode!**

> **Tips:** Gabungkan **[Style Guide Global]** + teks **`Scene: ...`** untuk tiap gambar, dan generate dalam satu chat yang sama agar wajah & gaya **Inspektur Juno** tetap konsisten!

---

## Style Guide Global (tempel di awal setiap prompt)

```text
Vibrant 2D expressive comic-book cartoon illustration inspired by Ace Attorney and modern detective comic strips, 16:9 landscape aspect ratio, bold clean ink outlines, lively vivid cel-shaded colors, funny exaggerated facial expressions, NO text, NO words, NO letters. Recurring detective character: Inspector Juno, a cheerful eccentric young-adult detective with messy dark hair, round glasses, amber scarf, and a navy trench coat.
```
